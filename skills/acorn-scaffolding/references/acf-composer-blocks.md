# ACF Composer block classes

Deep reference for the block class generated by `acf:block` (ACF Composer 3.4.6). Loaded on demand from SKILL.md.

## Discovery and registration

- ACF Composer scans the sub-folders of `app/` whose names match its known kinds (`Blocks`, `Fields`, `Options`, `Widgets`…) and registers every non-abstract subclass of its `Composer` base, using `app()->getNamespace()` for class names. Partials are not registered on their own.
- On `acf/init` (priority `config('acf.hookPriority', 100)`) each block is composed: if `$name` is blank the block is skipped; `$slug` defaults to the kebab-case name; the view defaults to `blocks.{slug}`; the block name is `acf/{slug}`.
- Registration: when `<storage>/framework/cache/acf-composer/blocks/{slug}/block.json` exists it calls `register_block_type($jsonPath)`; otherwise it builds the settings array, applies `acf/register_block_type_args`, and registers through ACF. Duplicate names throw `Block type [acf/x] is already registered.`
- If the project extends a base block class (custom stub), extend that class, not `Log1x\AcfComposer\Block`.

## Class shape

```php
<?php

namespace App\Blocks;   // or your project namespace

use Log1x\AcfComposer\Block;
use Log1x\AcfComposer\Builder;

class PricingTeaser extends Block
{
    public $name = 'Pricing Teaser';
    public $slug = 'pricing-teaser';          // drives acf/{slug}, blocks.{slug}, CSS file names
    public $description = 'Short plan comparison with a call to action.';
    public $category = 'design';
    public $icon = 'money-alt';               // dashicon name without "dashicons-"
    public $keywords = ['pricing', 'plans'];
    public $post_types = ['page'];            // [] = every post type
    public $parent = [];                      // direct parents allowed
    public $ancestor = [];                    // ancestors allowed at any depth
    public $mode = 'preview';

    public $spacing = ['padding' => null, 'margin' => null];   // null = control enabled
    public $supports = [
        'align' => false,
        'anchor' => true,
        'mode' => true,
        'multiple' => true,
        'jsx' => true,                        // required for <InnerBlocks />
    ];

    public $styles = ['light', 'dark'];       // only when there are visual variants

    public $example = [                       // preview data: inserter and editor preview only
        'title' => 'Pick the plan that fits your team',
        'plans' => [['name' => 'Starter', 'price' => 'Free']],
    ];

    public function with(): array
    {
        return [
            'title' => (string) (get_field('title') ?: ''),
            'plans' => $this->normalizePlans(get_field('plans')),
        ];
    }

    protected function normalizePlans(mixed $plans): array
    {
        return is_array($plans) ? array_values(array_filter($plans, 'is_array')) : [];
    }

    public function fields(): array
    {
        $fields = Builder::make($this->slug);

        $fields
            ->addText('title')
            ->addRepeater('plans', ['min' => 1, 'max' => 4])
                ->addText('name', ['required' => true])
                ->addText('price')
            ->endRepeater();

        return $fields->build();
    }

    public function assets(array $block): void
    {
        // See the assets() rule in SKILL.md before enqueuing here.
    }
}
```

If the project wraps `get_field()` (for a language-aware helper, a preview fallback, or a typed accessor), use the wrapper.

## Property notes

| Property | Notes |
|---|---|
| `$slug` | Set explicitly. Renaming it on an existing block orphans every stored instance (`<!-- wp:acf/old-slug -->`) |
| `$supports` | snake_case keys are also exposed camelCased (`align_text` → `alignText`) |
| `$styles` | Plain names, `['name' => …, 'label' => …, 'isDefault' => true]` arrays, or `['dark' => true]` (name => isDefault). The first entry becomes default when none is marked |
| `$example` | Field name => value. `false` disables the inserter preview. Shown in the inserter and in the editor preview |
| `$template` | Default inner blocks; see `inner-blocks.md` |
| `$uses_context` / `$provides_context` | Block context (snake_case property names in ACF Composer 3) |
| `$mode` | `preview`, `edit` or `auto` |
| `$align`, `$align_text`, `$align_content` | Default alignment values |

`$name` and `$description` are read when the class loads. For translated inserter labels use `--localize` (the stub overrides `getName()` / `getDescription()` with `__()`).

## What the view receives

`render()` passes everything from `with()` plus:

- `$block`: the block instance. Useful members: `$block->preview` (true inside the editor), `$block->style` (active `is-style-*` name), `$block->classes`, `$block->template` (JSON string), `$block->content` (inner HTML), `$block->post_id`, `$block->context`, `$block->block` (raw block array).
- `$attributes`: a `ComponentAttributeBag` with block-support classes, inline style and anchor `id`. **Empty in the editor preview** (`getHtmlAttributes()` returns `[]` when `$this->preview` is true), because WordPress puts those on its own wrapper there.

## Data shaping and tests

Keep `with()` thin and move shaping into protected methods that take plain values. They can be unit tested without WordPress by instantiating the class without its constructor:

```php
$block = (new \ReflectionClass(PricingTeaser::class))->newInstanceWithoutConstructor();
$method = new \ReflectionMethod(PricingTeaser::class, 'normalizePlans');
$this->assertSame([], $method->invoke($block, null));
```
